# SONOS-INSPIRED WEBSITE

## 1. Project Theme
This project is a multi-page website inspired by the modern, minimalist design of the Sonos website. It focuses on clean layouts, product presentation, large visual sections, consistent navigation, and responsive styling.

## 2. Technologies Used
- HTML5
- CSS3

## 3. Website Pages

### Home Page — index.html
Introduces the website through a hero section, featured products, promotional sections, and other visual content.

### Shop Page — shop.html
Presents products in an organized layout for visitors to browse.

### New Arrivals Page — new-arrivals.html
Highlights newly added products using product cards and related visual elements.

## 4. Project Structure
- `index.html` — Home page
- `shop.html` — Shop page
- `new-arrivals.html` — New Arrivals page
- `style.css` — Shared website styling
- `shop.css` — Shop-specific styling, if present
- `new-arrivals.css` — New Arrivals-specific styling
- `media/` — Images and videos used by the website
- `README.txt` — Project documentation

Note: Keep this list consistent with the files and folders actually included in your submission.

## 6. How to Run the Project
1. Open the project folder.
2. Open `index.html` in a web browser.
3. Use the navigation links to visit the other pages.

## 7. Customization
- Edit HTML files to change page text, links, and content.
- Edit `style.css` to change shared styling.
- Edit page-specific CSS files to change individual pages.
- Place images and videos in the `media` folder and make sure their paths match the filenames used in the HTML.
